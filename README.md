# DSS150P Lab 4: Reproducible Dengue Severity Pipeline

Individual reproduction of a group Predictive Analytics project
(dengue severity prediction, 41 Philippine cities, 2016–2021).

## Attribution
Dataset, problem statement, feature definitions, model family and
hyperparameters come from the prior group project `dengue-ph-prediction`
(Candelaria, Santos, Vicente).
All engineering in this repository (pipeline, Docker, Airflow, tests, docs)
is individual work.
